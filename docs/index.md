# Agent Zen documentation

Agent Zen is a calm local control plane for Codex sessions. Codex owns session state; Agent Zen observes it, derives a read-only focus board, and keeps human Ideas and Logbook notes separate.

The core domain language lives in [CONTEXT.md](../CONTEXT.md). The [session state model assessment](2026-08-25-session-state-model-assessment.md) records the current evidence, model gaps, and observer-only path toward separate Planning and Idle states.

Start with the [FAQ](faq/README.md) for the live connection, native request handling, daemon persistence, exact stage rules, refresh cadence, project and worktree identity, focus limit, Quick Capture, and native macOS status.

The [architecture decision records](adr/README.md) preserve the product and integration decisions behind the current build.
