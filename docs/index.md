# Agent Zen documentation

Agent Zen is a calm local control plane for Codex and Claude Code sessions. Each agent owns its session state; Agent Zen observes it, derives one read-only focus board, and keeps human Ideas and Logbook notes separate.

The core domain language lives in [CONTEXT.md](../CONTEXT.md). The [session state model assessment](2026-08-25-session-state-model-assessment.md) records the accepted boundaries and includes a visual map of the implemented observer-only classifier.

Start with the [FAQ](faq/README.md) for the live connection, native request handling, daemon persistence, exact stage rules, refresh cadence, project and worktree identity, focus limit, Quick Capture, and native macOS status.

The [architecture decision records](adr/README.md) preserve the product and integration decisions behind the current build.
